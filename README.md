# 国庆7天 · 杭州当天往返（学生党版）

单文件网页：选择杭州周边城市，看车程、票价、景点、糯叽叽美食，生成 7 天计划。

- 网页：index.html
- 说明：发布说明.txt
- 预约景点：可在城市卡片或集中清单中圈选，生成按城市分组的预约路线
- 首页：使用插画主视觉和可点击的华东互动地图，地图选城会同步到行程
- 深色模式：导航栏右侧切换，默认跟随系统偏好并记住选择
- 12306 开售倒计时：出行备忘页实时倒数下一个开售日，可开桌面通知提醒
- 导出日历 .ics：行程导出为日历文件（每天提前 1 小时提醒），也可只导出抢票提醒
- 分享链接：地址栏实时同步已选城市、出发日和全部设置，「复制分享链接」发出去即可还原方案

测试：`node smoke-index.mjs`（依赖 jsdom，覆盖加载、行程、倒计时、ics、分享、主题、链接还原共 27 项）
